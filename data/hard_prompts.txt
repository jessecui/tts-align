# Hard prompts for TTS preference dataset.
# One prompt per line. Lines starting with '#' are skipped.
# Curated to stress-test the model along axes that tend to expose alignment gaps:
#   - long sentences (40+ words, multiple clauses)
#   - numbers (years, decimals, phone numbers, ordinals, large numbers)
#   - abbreviations and acronyms
#   - code-switched / non-English words
#   - unusual proper nouns
# Edit / extend as you go — this is a starter set, not the final list.
